## 💫 Sobre o Projeto

Um **site romântico interativo** criado por **Kauê** com todo o seu amor para **Gyovanna**. Mais do que um site, é um universo digital eternizando cada momento da nossa história — desde o primeiro olhar em Anápolis, GO, no dia 20 de junho de 2025.

O projeto combina design elegante, animações fluidas e gamificação para criar uma experiência única e personalizada. Cada detalhe foi pensado com carinho, desde o mapa estelar astronômico real até os 12 minigames exclusivos com sistema de conquistas.

| 🏆 20 Conquistas | 🔐 Códigos Secretos | 📱 Mobile & Desktop |

<details>

</details>

<details>
<summary><strong>📝 3. Quiz de Amor</strong></summary>

- Destaque visual das combinações vencedoras

<details>

- Corações flutuantes em cada clique
- Toasts ao atingir combo 10 e 25

## 🔐 Códigos Secretos

> ⚠️ **Atenção:** Esta seção é o painel de cheats. No site, estes códigos **não são divulgados** em nenhum lugar visível.

### 🕹️ Konami Code

```
↑  ↑  ↓  ↓  ←  →  ←  →  B  A
```

Abre um overlay especial com confetti e mensagem secreta de amor.

---

### ⌨️ Código de Texto Secreto

Sem clicar em nenhum campo de texto, **apenas digitando**, escreva:

```
KAUEAMAGYOVANNA
```

> Isso abre o **Painel Cheat** com a opção de desbloquear todas as 20 conquistas de uma vez.

---

### 👑 Como resgatar todas as conquistas de uma vez

1. Digite `KAUEAMAGYOVANNA` com o teclado (sem focar em input)
2. O painel secreto abrirá automaticamente
3. Clique no botão dourado **"Desbloquear todas as conquistas"**
4. 🎉 Confetti + toast + todas as 20 conquistas desbloqueadas

## 🌌 Mapa Estelar

O mapa foi construído com **coordenadas astronômicas reais** para Anápolis, GO (16.33°S, 48.95°W) no dia **20 de junho de 2025 às ~21:00**.

| Constelação | Estrelas Destacadas | Curiosidade |
|------------|-------------------|-------------|
| 🦂 **Escorpião** | Antares, Shaula, Graffias | Quase no zênite! Nossa constelação 💕 |
| ✝️ **Cruzeiro do Sul** | Acrux, Gacrux, Mimosa | Sempre visível do hemisfério sul |
| 🐾 **Centauro** | Alpha Centauri (-0.27 mag) | O sistema estelar mais próximo do Sol |
| 🏹 **Sagitário** | Kaus Australis, Kaus Media | Aponta para o centro da Galáxia |
| 🐕 **Cão Maior** | Sirius (-1.46 mag) | A estrela mais brilhante do céu noturno |

> **Antares** — supergigante vermelha 700× maior que o Sol — brilhava intensamente no zênite de Anápolis naquela noite. O universo estava assistindo. 🔴

**Interatividade:**
- `hover` nas estrelas → tooltip com nome, informação e magnitude
- `click` nas estrelas → efeito de burst + confetti
- Filtros SVG com `feGaussianBlur` simulam o brilho real

## 🛠️ Tecnologias

```
HTML5           Estrutura semântica, acessível, mobile-first
CSS3            Custom Properties, Grid, Flexbox, Animations, Glassmorphism
JavaScript ES6+ Vanilla JS puro, Canvas API, LocalStorage, IntersectionObserver
Google Fonts    Cormorant Garamond + Plus Jakarta Sans
Spotify         Embed iframe com tema escuro integrado
DiceBear API    Avatares placeholder enquanto fotos reais não são adicionadas
```

### Por que Vanilla JS?

- ✅ **Zero dependências** — sem npm, sem bundler, sem framework
- ✅ **Carregamento instantâneo** — arquivo único, sem requests extras
- ✅ **Funciona offline** — após cache das fontes Google
- ✅ **Facilmente editável** — qualquer editor, sem setup
- ✅ **Deploy trivial** — arrasta o index.html e funciona

## 🌐 Deploy no GitHub Pages

```bash
# 1. Fork ou clone este repositório
git clone https://github.com/SEU_USUARIO/SEU_REPO.git
cd SEU_REPO

# 2. Personalize (imagens, textos, datas)

# 3. Commit e push
git add .
git commit -m "💕 Meu site romântico para Gyovanna"
git push origin main

# 4. Ative o GitHub Pages
# GitHub → Settings → Pages → Source: Deploy from branch
# Branch: main → / (root) → Save

# 5. Acesse em ~2 minutos:
# https://SEU_USUARIO.github.io/SEU_REPO
```

> 💡 O site funciona **100% no GitHub Pages gratuito** — sem servidor, sem banco de dados, sem custos.

## 🎨 Personalização

### Trocar cores (CSS Variables)

```css
/* style.css — linha 3 */
:root {
  --rose:    #e8647a;  /* Cor principal */
  --purple:  #9b7ccd;  /* Cor secundária */
  --gold:    #c9956e;  /* Cor dourada */
  --bg:      #030209;  /* Background principal */
}
```

### Adicionar fotos reais

Substitua os arquivos em `images/`:

```
images/hero-photo.jpg    → Foto do casal (quadrada, 400×400px ideal)
images/gallery-1.jpg     → Foto vertical (proporção 3:4 ideal)
images/gallery-2.jpg
images/gallery-3.jpg
images/gallery-4.jpg
images/album-cover.jpg   → Capa da música (quadrada)
```

### Mudar a data de início

```javascript
// index.js — linha 7
const START = new Date('2025-06-20T20:30:00-03:00');
//                      AAAA-MM-DD HH:MM:SS   timezone
```

### Adicionar palavras ao Wordle

```javascript
// index.js
const W_WORDS = ['TUDO', 'AMOR', 'ALMA', 'ROSA', 'FLOR', ...];
//               ↑ Sempre a primeira palavra (pode mudar)
```
