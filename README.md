## ✨ O que é esse site?

Um site romântico, interativo e completamente animado, criado por **Kauê** com todo o seu amor para **Gyovanna**. Com **12 minigames exclusivos**, mapa estelar real de Anápolis/GO, conquistas desbloqueáveis, código secreto cheat, Snake, jogo de digitação e muito mais.

## 📐 Estrutura do Projeto

## 🔐 Segredos & Cheats

### 🕹️ Konami Code
Digite no teclado: `↑ ↑ ↓ ↓ ← → ← → B A`
> Overlay especial com confetti e mensagem secreta de amor!

### ⌨️ Código Secreto de Texto
Sem clicar em nenhum campo de texto, **só digitando**, escreva:
```
KAUEAMAGYOVANNA
```
> Abre o painel cheat com opção de **desbloquear todas as 20 conquistas de uma vez**!

## 🚀 Como Usar

```bash
# 1. Clone o repositório
git clone https://github.com/SEU_USUARIO/SEU_REPO.git

# 2. Adicione as fotos do casal em images/
#    hero-photo.jpg, gallery-1.jpg até gallery-4.jpg, album-cover.jpg

# 3. Abra index.html direto no navegador
#    (não precisa de servidor!)

# 4. Para hospedar no GitHub Pages:
#    Settings → Pages → Source: main branch → Save
#    Acesse: https://SEU_USUARIO.github.io/SEU_REPO
```

## 🛠️ Tecnologias

```
HTML5        → Estrutura semântica, acessível e responsiva
CSS3         → Custom Properties, Animations, Grid, Flexbox, Glassmorphism
```

**Zero frameworks, zero dependências** — funciona offline após carregamento das fontes.
